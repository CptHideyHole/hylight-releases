What you get

  • Light and shadowSoft sun shadows, glowing torches and lamps, a darker night.
  • Water and skyReflections, light through clouds, weather you can see coming.
  • The far horizonOn Farlight servers, distant land drawn far past the normal view.

Installing

  1. Download HylightSetup.exe from the newest release.
  2. Run it. Windows may show “Windows protected your PC”, because Hylight is new and not yet signed. Click More info, then Run anyway.
  3. Click Install Hylight. Close Hytale first if it’s open.
  4. Start Hytale the way you always do. In the game, press Shift + F8 for Hylight’s settings.

Hylight keeps itself working after Hytale updates and updates itself, so you only do this once. You can turn both off in the installer and in the Hylight window.

Removing it

Open Hylight from the Start menu and choose Uninstall Hylight, or find it in Windows Settings under Apps. Hytale goes back to how it was. Your Hylight settings are kept in case you come back.

Privacy

Hylight sends nothing about you anywhere. It only downloads its own updates from this page’s release list, and on Farlight servers it receives the far terrain from that server. If you report a problem, you create the report yourself and choose whether to send it.
