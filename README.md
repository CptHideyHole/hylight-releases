# Hylight releases

Hylight is an optional graphics add-on for the Hytale client on Windows: softer shadows, better light, water and
clouds, and land all the way to the horizon on servers that run its companion, Farlight. This repository holds the
official downloads and nothing else.

**Download page:** https://cpthideyhole.github.io/hylight-releases/

## Download

Get Hylight only from this repository's [Releases](../../releases) page or the download page above. Each release
lists a SHA-256 hash for every file. A copy from anywhere else is not from us.

Test builds are marked as pre-releases.

## What this repository is not

- There is no source code here, and pull requests are not accepted.
- Hylight is a fan-made project. It is not affiliated with or endorsed by Hypixel Studios.
