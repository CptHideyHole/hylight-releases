# Lumen releases

Lumen is an optional graphics add-on for the Hytale client. This repository holds
the official downloads and nothing else.

## Download

Get Lumen only from this repository's [Releases](../../releases) page. Each release
lists a SHA-256 hash for every file. A copy from anywhere else is not from us.

No release has been published yet.

## What this repository is not

- There is no source code here, and pull requests are not accepted.
- Lumen is a fan-made project. It is not affiliated with or endorsed by Hypixel Studios.
